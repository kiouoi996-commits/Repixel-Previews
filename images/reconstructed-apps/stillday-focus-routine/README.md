## Layering and CSS

* All headings, descriptions, date labels, durations and card titles stay editable HTML text.
* All background cards, controls, timeline nodes and selection rings are CSS/UI primitives; SVG paths contain no button background.
* `hero-sunset-sea.png` already includes a soft sun disk, sea, birds, and alpha-feathered image edges; do not duplicate sunset disk with a CSS circle.
* `forest-rain.webp` and `morning-mist.webp` have no overlay captions or buttons.
* `forest-rain.webp` is reused in mini player, rather than exporting a duplicate.
* Use object-fit: cover and object-position specified in manifest; round corners are CSS, not baked into photos.
* System status-bar icons were intentionally excluded.

## Reconstruction uncertainty

Exact original fonts, unseen image content and original shadow/blur algorithm cannot be inferred reliably. Generated/retouched detail for covered forest and mist content is approximate. WebP art was enlarged from screenshot-quality reference; dimensions are 3× but do not imply original photographic sharpness.
