# Hidden Coasts Travel Discovery

Screenshot-derived asset reconstruction for the three-screen travel UI.

- Source screenshot: 1448×1086 px.
- Project slug: `hidden-coasts-travel-discovery`
- Raster assets: 14 WebP files in `images/`.
- SVG icons: 17 files in `icons/`.
- Reused raster assets are not duplicated.
- System status-bar graphics are intentionally omitted.
- All image measurements are estimates from the supplied raster screenshot, not original design tokens.

## Files

- `manifest.json` — machine-readable asset map, measurements, reuse, UI primitives, reconstruction notes and per-image prompts.
- `analysis.md` — detailed screen-by-screen and asset-by-asset analysis.
- `asset-table.csv` / `asset-table.md` — requested usage table.
- `images/` — screenshot-derived WebP reconstructions.
- `icons/` — transparent SVG glyphs with `currentColor`.

## Important reconstruction note

These are **reconstructions from the screenshot**, not the original source photos. Pixels hidden by UI, clipping, rounded corners or overlapping mosaic items are not knowable from the screenshot. Clean visible interior regions were used for most photos; hidden portions of the hero banner were locally reconstructed after UI removal.
