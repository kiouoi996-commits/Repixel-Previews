# Nora Modern Living Storefront

Screenshot reconstruction of one 1024×1536 furniture ecommerce storefront.

**Publication status:** 16 original SVG graphics (including wordmark) published. Raster photographs and thumbnails exist in the local delivery archive but have not yet been transferred into this repository. Do not treat their manifest paths as available public URLs.

The photographs are reconstructed from a flattened screenshot rather than original source photos; transparent PNG cutouts are approximate. Do not combine interface text, buttons, badges or CSS circles into photos.

Project graphics: `icons/`; intended raster photo files: project root. All UI labels, ratings, navigation, circular button backgrounds and promo badges should be rendered by the application.
