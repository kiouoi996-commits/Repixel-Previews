# Icons Never Fade — Grand Tourers

Asset reconstructions based on a **1448 × 1086 px** user-supplied composite screenshot showing three classic-car mobile screens (editorial home, DB5 timeline, Ferrari auction).

6 WebP photos plus 13 clean SVG icons. All photographic content is reconstructed, **not original photography**. The initial image model did not create six independent files: it returned a consolidated draft, from which the final images were isolated and individually prepared, including manual masking for the Mercedes and DB5. Do not mistake the output pixels for unseen original photos. Exported resolution 3× by interpolation; intrinsic sharpness remains bounded by reference pixels.

Refer to `manifest.json` for pixel coordinates and proportions estimated from the screenshot, asset mappings, colors and CSS object-fit recommendations.

All text and UI overlays remain CSS/HTML, and system status icons are deliberately excluded.
