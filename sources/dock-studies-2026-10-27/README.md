# Three menu selection studies

The supplied stills establish the visual language. Motion is newly authored. Reference WebPs are quality-95 exports; their bytes differ from the attached PNGs. Original attachment hashes are recorded in the card metadata. The drawing and spring model in scene.mjs are shared between live examples and the deterministic 30 fps recorder.

Normal examples start idle. Click buttons or use ArrowLeft, ArrowRight, Home, End. Replay is opt-in. No real app routes or create actions are simulated by this selection-only example. The downstream implementation must bind the host's actual navigation and actions.

Each video is 1200×676, 30 fps, 270 frames, silent H.264 yuv420p, faststart. Initial and final source frames are byte-identical. Labels use a metrically compatible sans-serif reconstruction; the original screenshot font is unknown.
