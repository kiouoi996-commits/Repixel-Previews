# AMBRA and Haven desktop navigation hover studies

Six newly authored effects using desktop navigation content from the selected AMBRA interior and Haven Ocean Light archives. These effects are new; the archive provenance records the menus they were composed around. No original application source or private archive is included in this public project.

The canonical preview is an opaque 1080 × 608 scene on uniform `#11121B`. The two menus are deliberately recomposed at 1.25 times their source text sizes and centered around y = 304. The isolated presentation does not prescribe moving an installed site's navigation out of its original top header. Keep the host's placement, responsive rules, language control, login, inquiry and navigation actions when integrating an effect.

## Exact resources

`geometry.json` contains frozen, positioned glyph paths from Cinzel 600 and Plus Jakarta Sans 400, 500, 600 and 700. Kerning is enabled; ligatures are disabled so each letter remains independently addressable. Font source URLs and hashes, source archive identities and the selected source file hashes are in `source-provenance.json`. The font licenses accompany the separately published WOFF resources. Haven's mountain mark is an authored vector reconstruction of the source icon's role and proportions. All hover effects and the pointer drawing are authored here.

`effects.mjs` is the shared pure scene renderer. It specifies every coordinate, ink, mask, easing equation and hover state. The same renderer is used in the browser demo and video export; it has no random values, time-dependent external services, images or network dependencies.

## Run and render

Requires Node 22 or later, Python 3, the system librsvg 2, Cairo and GObject shared libraries, plus FFmpeg with H.264 support. No npm installation is needed.

```sh
node build-demo.mjs
node render.mjs --stills
node render.mjs
```

Open `demo.html` in a browser to try all six effects. It is standalone and does not load remote scripts or fonts. The transparent vector resources are generated by `build-demo.mjs`.

The video export is 1080 × 608, 30 fps, 240 frames, eight seconds, H.264, yuv420p, CRF 18, with fast-start metadata and no audio. Exported first and final frame PNG bytes must be equal. Videos, WebP posters and their SHA-256 hashes are recorded in the render manifest. The pointer hovers each of the four links from 0.65–1.75, 1.95–3.05, 3.25–4.35 and 4.55–5.65 seconds, then returns to rest by 5.9 seconds. This scheduled pointer is a gallery demonstration only.

The browser demo provides semantic focusable controls over the exact visual geometry. Real pointer hover and keyboard focus drive effects in interactive mode. Reduced-motion mode holds a static state. Animation pauses when the document is hidden or the stage leaves the viewport, and is disposed on page exit. Clicks dispatch a bubbling `navigation-action` CustomEvent with `{ menu, action, label }`. Connect it to the host's existing handlers. The demo's outside-scene status is only an integration stub, and is excluded from the videos.

AMBRA's first three links request `scene-01`, `scene-02` and `scene-03`; Contact requests the inquiry flow. The language and hamburger controls keep their own events. All four Haven links request the reservation flow; Login requests its separate login flow. The original Haven logo action prevents its placeholder `#` navigation. Do not invent new destinations or replace real host behavior with this stub.

Adaptation should keep the client's own logo, labels, routes, actions, typography and palette, applying only the chosen hover mechanism. Use full-label duplicates for rollover, sized masks without layout changes, and font-ready measurement when generating a client version. Do not stretch source glyphs or inject the reference brand into a client navigation.
