# Sculpt — Ceramic Decor

A three-view, single-screen reconstruction based on the supplied 1448 × 1086 still. The app is editable HTML/CSS/JavaScript with thin SVG icons and separate generated photography. The original source code, font identity, unseen image pixels and motion are unconfirmed. Roboto is a visually matched replacement; the images are ImageGen reconstructions.

Open sculpt-app.html through an HTTP server to use the interactive comparison app. Its dependencies use immutable public URLs. Add ?app to remove the comparison presentation wrapper. The three initial app screens omit OS status decoration. This comparison app is a local commerce demo: checkout and profile are host integration boundaries.

The film is an authored nine-second 1448 × 1086 30 fps sequence of these screens and state changes. It contains no sound. The final eighteen source PNG frames equal the first idle frame; lossless equality is not claimed after H.264 encoding. The initial and final states are visually the same.

production-assets.json records individual media paths, sizes, SHA-256, font resources, generated-image provenance and interaction verification. All referenced assets were fetched anonymously and matched before the website card was published.
